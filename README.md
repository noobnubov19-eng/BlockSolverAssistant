# Block Solver Assistant — MVP 0.1

Android-помощник для игры с полем 8x8. Он:

- получает экран через MediaProjection;
- распознаёт занятые клетки на поле;
- распознаёт три зелёные фигуры снизу;
- перебирает порядок 3 фигур и все допустимые позиции;
- показывает на поле подсказку 1 → 2 → 3 поверх игры;
- ничего сам не нажимает и не модифицирует игру.

## Важно

Первая версия откалибрована под присланный скриншот 720x1600:
- поле примерно x=40..668, y=362..990;
- 8x8;
- фигуры зелёные.

Если игра сдвигает поле, меняется тема/цвет или навигационная панель, нужно подправить 4 коэффициента в `FrameAnalyzer.kt`.

## Запуск

1. Открыть папку в Android Studio.
2. Дождаться Gradle Sync.
3. Собрать/установить на Android.
4. В приложении нажать `Разрешить поверх окон`.
5. Нажать `Запустить помощник` и разрешить захват экрана.
6. Перейти в игру. На поле появятся контуры и номера 1, 2, 3.

На Android 14+ система требует разрешение пользователя на каждую новую сессию захвата экрана.

## Сборка APK через GitHub Actions

В проект добавлен workflow `.github/workflows/build-apk.yml`.
После загрузки проекта в GitHub открой вкладку Actions → `Build Android APK` → Run workflow.
Готовый APK появится в Artifacts под именем `BlockSolverAssistant-debug`.

Для первого теста при системном запросе MediaProjection выбирай захват **всего экрана**, потому что MVP откалиброван под полный экран 720×1600.
