Все точки и тропы сохраняются в памяти телефона. GPS работает без мобильного интернета. Для леса заранее скачай спутниковый район.

Прогресс стройки

Офлайн спутник

Скачай район сегодня при хорошем интернете. Завтра в горах приложение будет брать сохранённые тайлы из памяти телефона.
Спутниковая подложка: Esri World Imagery. Использование и кэширование карт регулируется условиями поставщика.

Резервная копия

Проект автоматически сохраняется после каждого изменения. Отдельную JSON-копию можно сохранить в папку «Загрузки/СтройКарта».
